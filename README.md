# CLICKER: GODFORGE

Dark-fantasy hybrid idle clicker for Android, built with Godot 4.5.1.

## Development

- Target: Android ARM64, landscape orientation
- Engine: Godot 4.5.1
- Workflow: GitHub Actions only; no manual code editing or Termux
- Gameplay: active tapping, idle income, upgrades, boss encounters, ascension-ready progression
- Visual direction: obsidian, ember gold, crimson runes, animated loading/title screen

The Android build workflow validates the project and exports a debug APK when possible. The game is an early playable foundation; rewarded ads are planned behind an abstraction and will not be falsely presented as integrated until a real ad SDK is configured.
